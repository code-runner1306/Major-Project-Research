Gated DeltaNet research glossary

The letters belong to different experiments. A labels change training data. E labels name published-harness tests. Scalar and channel-wise describe gate shape. Default, mean decay, and joint describe how a gate starts training.

Experiment map

TermMeaning in this project
ArmA version of an experiment. A0–A4 are training-data arms in our custom overwrite study.
CellA specific task setting. E1, E4 and E5 are cells in the separate Anatomy harness.
ConditionA choice such as scalar decay with mean-decay initialization. A seed identifies a repeat of that condition.
CheckpointSaved model weights at a particular training step. A frozen-checkpoint test changes evaluation inputs or gates while keeping the trained weights.
dualgooseThe upstream code repository for Boesch and Wee’s Anatomy of Associative Recall in Fixed-State Recurrences. This project vendors it at commit 8ca624a in third_party/dualgoose and adds a scalar arm.
armed_gdnThe published dualgoose arm. Despite scalar terminology in the upstream paper, the pinned executable emits one decay per key channel. It uses sigmoid decay and a bidirectional setup in the cells we reproduced.
armed_gdn_scalarOur matched dualgoose extension. The decay projection emits one value shared over key channels. This harness and our main synthetic recipe are separate implementations.

A0–A4: overwrite training data

TermMeaning in this project
A0 · ControlOriginal data: fixed nominal query distance 8, one rewrite, and block-first examples allowed.
A1 · Varied distanceTrain on nominal distances 8 through 16, still with one rewrite and block-first examples allowed.
A2 · No block-firstKeep distance 8 and one rewrite, but reject training examples where all target writes precede every unrelated write.
A3 · Mixed rewritesTrain with one, two, or three rewrites at distance 8. Block-first examples are still allowed.
A4 · Distance and rewritesCombine A1 and A3: each distance 8–16 with each rewrite count 1–3. Block-first examples remain allowed.
Block-firstAll writes to the queried key occur before the unrelated writes. An example can expose a positional cue if the query always follows at the same distance.
Rewrite countNumber of replacements after the initial write. One rewrite means two writes total for that key.
Query distanceSeparation between writes and the query. Nominal distance is the generator’s requested setting; realized distance is the gap in the actual example.
Positional shortcutUsing a position or layout cue to select the answer. In A0, the second write is always the latest; extra rewrites can turn that cue into a stale answer.
Data interventionChange the training examples and retrain. A1 and A3 target different measured failures; A4 combines them. The result is specific to this generator.

E1, E4, E5: published-harness cells

TermMeaning in this project
E1 · Constrained stateMQAR with 32 associations, key width 32, one layer, and 6,000 steps. Mean accuracy was 99.98% scalar versus 98.30% channel-wise; both locked in on 10/10 seeds.
E4 · Distractor haystackLength 64, four pairs, distractors, two layers, two heads, and 3,000 steps. Both variants locked in on 6/10 seeds; mean channel-wise accuracy was descriptively higher.
E5 · Colliding keysE4-style setup with key collisions and a rebinding control. Scalar locked in on 5/10 seeds, channel-wise on 3/10. The difference is uncertain.
E6 · Gate interventionAlter the evaluation gates of already trained channel-wise checkpoints from E1, E4, and E5. It tests what those checkpoints depend on.
Lock-inA run crosses a prescribed accuracy threshold: 90% for E1, 80% for E4 and E5. Two arms can tie on lock-in and differ in mean accuracy.
Rebinding controlChange the associations to test whether predictions follow the bindings in the input. Consult the harness for the precise intervention in each cell.
CollisionKeys compete under the harness’s collision construction, making their associations harder to distinguish.
BidirectionalForward and backward recurrent passes are combined. This is a property of these published harness cells, separate from the causal synthetic recipe.

Decay and initialization

TermMeaning in this project
Scalar decayOne forgetting multiplier per head at each token, shared by all key coordinates in that head.
Channel-wise decayOne forgetting multiplier per key coordinate at each token. Some tracks of the state can decay faster than others.
Default initializationUse the model's normal sampled initial decay rates and offsets. Both scalar and channel-wise models have a default condition.
Mean-decay initializationCalled calibrated in artifact keys. Fit the starting offset so the empirical arithmetic mean of alpha on training activations matches the target for each gate. Leave the initial rate unchanged.
Joint initializationFit both the starting offset and rate. Match mean log decay and an average softplus sensitivity target. It is a DAMI-style adaptation, not a new gate architecture.
Mean alpha vs. mean log alphaArithmetic mean summarizes a typical multiplier. Mean log alpha measures average log attenuation, which adds across steps when multiplying decay factors.
Half-life targetThe number of steps for a constant isolated decay to halve its contribution. The four layer targets are 16, 32, 64, and 128 tokens. They describe initialization, not measured retrieval lifetimes.
Offset / rateThe decay formula contains a learned additive offset dt_bias and a positive rate exp(A_log). They affect how much attenuation the same activation produces.
Softplus sensitivityHow much softplus changes when its input changes. Its derivative is sigmoid. Joint fitting targets layer-average sensitivities 0.25, 0.75, 0.75, 0.25.
CalibrationFit starting gate settings on training activations before optimizer training. Afterward those parameters remain trainable.
Dynamic / original gateUse the trained gate's usual input-dependent output.
Fixed per-channel meanDuring evaluation, replace a dynamic channel gate with fixed values that may differ by channel. This keeps channel differences and removes input variation.
Per-token channel averageDuring evaluation, average the channels at each token. The shared value can still vary by token.
Fixed scalar meanDuring evaluation, use one fixed shared value in place of the original gate. This removes variation across both tokens and channels.
Decay-only productMultiply the alpha factors over a span. It measures attenuation due to those factors along the observed trajectory. The complete recurrence also includes writes, interactions, and readout.

Model, tasks and measurements

TermMeaning in this project
GDN / Gated DeltaNetA recurrent mixer combining controlled forgetting with a delta-rule memory update. The main synthetic recipe uses four blocks with one head each.
State, SA matrix holding the model’s working memory. In the synthetic recipe, each head’s state has 256 value rows and 128 key columns.
Key, value, queryKey = address, value = content, query = direction used to read. Memory and readout are learned vectors, not literal dictionary slots.
Alpha / betaAlpha scales existing state. Beta scales the delta correction. A filler token can still change beta and trigger a write.
Delta ruleCompare the value to what the current decayed state predicts for the key, then write back a correction proportional to beta.
ReadoutUse the current state and the query vector to produce a representation, then score candidate answer tokens.
Causal vs. fixed stateCausal limits which tokens a prediction can use. Fixed state means memory dimensions stay constant as the sequence grows. These are separate properties.
Associative recall / MQARRetrieve the value paired with a key. Multi-Query Associative Recall asks about several pairs in the same sequence. Main training uses four associations at length 64.
ZoologyThe source of the standard MQAR generator used here. The custom overwrite generator is separate.
Overwrite recallAsk for the latest value after replacing an earlier value for a key. A stale-value answer returns a previous value for that key.
Unrelated retentionAccuracy on a different key whose value should survive the target rewrite. All-query overwrite accuracy includes both latest-value and unrelated queries.
Answer-free evaluationErase earlier gold answer inputs before scoring. This prevents a model from using earlier correct answers as input; it is not autoregressive feedback.
Filler / length extrapolationOur frozen length sweep keeps four associations and inserts repeated token 0, the ordinary training filler, before the query region. Models trained at 64 tokens are evaluated at 64, 256, and 1,024.
Load stressChange the number of associations, for example from four in training to twelve at evaluation. Length stress increases the sequence length. The two can be varied independently.
Fresh confirmationEvaluation on newly generated, overlap-audited examples using a fixed protocol. It is distinct from an exploratory stress grid.
Seed / paired comparisonA seed controls repeatable randomness. Pairing compares variants under corresponding seeds and data conditions, so a difference is calculated within each pair.
Exact-query accuracyCorrect answer tokens divided by scored queries. For example, 301/1,024 is about 29.39%, regardless of how many examples contained those queries.
Percentage pointAbsolute difference between percentages: 98% minus 95% is 3 percentage points.
Paired sign-flip testCompare the observed paired difference with differences after flipping group labels within each pair. In E1 the exact two-sided result is p = 0.0078125.
Quantile / medianA percentile describes position in a distribution. The median is the 50th percentile; a 90th percentile near one does not mean most channels retained that much.
Checkpoint hashA fingerprint of the saved checkpoint bytes. Matching hashes confirm that analyses used identical stored checkpoints.
Training step / epochA step is one optimizer update. An epoch is one pass through the training examples. The synthetic cohort used 3,136 updates over 16 epochs.
AdamW / cosine scheduleAdamW updates learned parameters. The cosine schedule varies learning rate. The epoch-16 cutoff on a 64-epoch schedule left 85.4% of the peak rate scheduled.
Parameter count / recurrent-state sizeParameter count measures learned weights. State size measures working memory per sequence. Channel-wise decay added 66,040 parameters here at the same state dimensions.
