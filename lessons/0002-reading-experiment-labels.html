Lesson 2 · Research design

Read an experiment label

The letters belong to different experiments. A labels change training data. E labels name published-harness tests. Scalar and channel-wise describe gate shape. Default, mean decay, and joint describe how a gate starts training.

Read “A4, channel-wise, seed 44” as “train on variable query gaps and rewrite counts, give each key coordinate its own decay, and use repeat 44.” Read “E4, scalar” as “run the scalar model on the published distractor-haystack cell.”

Try it from memory

Which comparison isolates distance diversity: A0 versus A1, or A0 versus A4?

A0 versus A1. A4 also changes rewrite diversity.

Can a model be both scalar and joint?

Yes. Scalar tells you how many decay values it emits per head. Joint tells you how its starting offset and rate were fit.

What does an E4 lock-in tie of 6/10 tell us?

Six seeds in each arm crossed 80% accuracy. Their mean accuracies can still differ.
