# IEEE conference paper

Upload the ZIP to Overleaf and set the main document to main.tex. Use pdfLaTeX and BibTeX with the supplied IEEEtran class.

The project contains the manuscript, bibliography, IEEEtran class, and four embedded vector PDF figures. Figure 1 shows the synthetic Gated DeltaNet architecture. Figure 2 shows the evaluation workflow. Figure 3 plots individual paired accuracy differences for synthetic recall and Anatomy. Figure 4 shows the decay-only diagnostic on inserted filler. The resource table reports optimizer-step timing and static model footprint.

The optional companion document supplement.tex contains replay diagnostics, exact E1 tests, and the final-layer product histograms. Select supplement.tex as the main document to build it separately. The conference manuscript remains main.tex.
